# Queue Rorschach

> Turn anonymous visitor paths into inkblot confessions.

A web analytics toy that takes real user journeys and renders them as abstract inkblot scenes. Visitors see what they mean, and your site gets a cognitive mismatch tax when interpretations split.

## Features
- Ingest pageview and clickstream sessions into anonymous path blobs
- Generate an inkblot image and LLM story from each session
- Score cognitive mismatch when two visitors interpret the same path differently
- Export a shareable Rorschach report with a suggested copy rewrite

## Stack
- Next.js
- OpenAI
- tRPC
- Recharts

## Getting started
```
npm install, set OPENAI_API_KEY, then npm run dev
```
